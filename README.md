# 性感美女提示词 Skill

想生成好看的美女照片，却总是遇到提示词不稳定、姿势不自然、服装说不清，甚至刚准备出图就被拦截？

这个 Skill 专门帮你生成可直接复制的中文性感美女摄影提示词。现代生活照、居家写真、古风人物、手机抓拍，都可以一句话生成，甚至精灵族，猫耳娘啥的都不在话下。

怎么来怎么性感~~~

## 安装

把仓库地址丢给codex：
```
请安装 https://www.github.com/yang0/sexy-beauty-prompts 
```

## 怎么用

直接告诉它你想要什么，例如：

> `随机生成一张卧室美女`

你也可以只说“写一条海边生活照”“来一条蕾丝睡衣风格”，剩下的交给它补全。

## 重要提醒

建议把生成的提示词复制到chatgpt网页端生图；

Codex 容易被拦截。
